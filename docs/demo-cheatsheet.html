Two honest caveats if asked:
  • Three Mapbox features are live: Geocoding (address → lat/lng, then the zone check), Search JS autofill in checkout, and the Optimization API for the Trip route and per-stop ETAs. The customer map itself is Leaflet with OpenStreetMap tiles, not Mapbox GL — our HLD named Mapbox GL but we shipped Leaflet. Don't claim Mapbox GL.
  • Robots drive in straight lines between stops rather than following the road geometry, and the customer map polls every 10 seconds rather than streaming.
  • A cancelled Order sends no email. The event map has no cancel case, so a Manager cancel is silent even though the backlog asked for a refund message.

Before you present
  • Reset the DB. The demo database goes stale relative to the migrations — on 11/16 it was missing 8 tables and every checkout page 500'd. Run cd backend && rm -f demo.db && python seed_demo.py --with-orders, then restart the backend.
  • The Stripe Card accordion is collapsed by default. Click Card to expand it before typing the card number, or your keystrokes go into a hidden field and nothing happens.
  • The Pay button did not respond to automated clicks but works with a real mouse. If nothing happens, click once more — don't spam it, Stripe will reject the duplicate.
  • Open the customer's Track tab before you dispatch. The map refreshes every 10 seconds, so opening it after the Robot has arrived shows nothing to watch.
  • Run the backend on port 5001, not 5000. macOS AirPlay Receiver owns 5000 and answers everything with 403, which looks exactly like a dead backend.
  • Start the backend with FLASK_RELOAD=0. The Flask reloader can lose the port on restart and take the whole server down mid-demo.
  • The Stripe whsec changes every time stripe listen starts. Copy the one it prints into backend/.env and restart the backend, or every payment is rejected as an invalid signature.
  • The Stripe badge in the checkout screenshot (small dark badge, right side) is Stripe's test-mode widget. Harmless, leave it.
  • Whole Milk stock is 4 right now. If you reset, it goes back to 4 — that is intentional, it drives the low-stock alert.
